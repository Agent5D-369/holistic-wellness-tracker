# AI Virtual Awakening Universal Skill v1.1
A portable, eight-stage holistic coaching experience inspired by Rick Broider's AI Holistic Wellness Coach and Six Pillars of Holistic Wellness.

## Use
Download this folder and install it using your AI host's documented Agent Skills workflow if supported. The folder name must match the SKILL.md name. For other assistants, copy universal-prompt.md into a new conversation and optionally supply the three references. Start with: "Guide me through my AI Virtual Awakening journey step by step." No API keys or dependencies are required. See tests/validation-report.md for verification scope; cross-host runtime testing remains pending.

## Master
This folder is the version-controlled master in the holistic-wellness-tracker repository. Future changes should use pull requests, increment metadata.version and update CHANGELOG.md. Keep personal coaching records out of Git.

## Provenance and rights
The original coach's mission, six pillars, adaptive approach and optional tracker recommendation informed this implementation. The eight stage names were recovered from December 19, 2024 project discussions; definitive manuscript verification remains pending. See references/source-notes.md for the recovered ebook's free-culture commitment and asset status. See DISTRIBUTION.md for scope of permissions and pending owner approval of skill licensing.
