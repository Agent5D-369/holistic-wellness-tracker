# AI Virtual Awakening Universal Skill v1.0
A portable, eight-stage holistic coaching experience inspired by Rick Broider's AI Holistic Wellness Coach and Six Pillars of Holistic Wellness.

## Use
Download this folder and install it using your AI host's documented Agent Skills workflow if supported. The folder name must match the SKILL.md name. For other assistants, copy universal-prompt.md into a new conversation and optionally supply the three references. Start with: "Guide me through my AI Virtual Awakening journey step by step." No API keys or dependencies are required. Host compatibility has not been runtime tested.

## Master
This folder is the version-controlled master in the holistic-wellness-tracker repository. Future changes should use pull requests, increment metadata.version and update CHANGELOG.md. Keep personal coaching records out of Git.

## Provenance and rights
The original coach's mission, six pillars, adaptive approach and optional tracker recommendation informed this implementation. The eight stage names are a proposed adaptation, not a verified original curriculum. Original plugin book and image assets have not been copied; review permissions and original curriculum before incorporating them. No open-source license is granted by this release; the owner should explicitly select distribution terms. Public visibility does not itself grant reuse rights. This is wellness coaching, not healthcare.
